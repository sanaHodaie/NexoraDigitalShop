## تصمیم‌های معماری

- React Native + Expo SDK 58 + TypeScript؛ FastAPI، PostgreSQL، SQLAlchemy و Alembic فعلی حفظ شده‌اند.
- موبایل با API کار می‌کند؛ هیچ اتصال مستقیم Neon، کلید بات یا کلید مدل در آن نیست.
- ساختار ماژولار داخل همان بک‌اند؛ از ایجاد microservice یا دیتابیس موازی در نسخهٔ پایه پرهیز شده است.
- TanStack Query برای دادهٔ سرور و React Hook Form/Zod برای فرم‌ها؛ Zustand در این نسخه لازم نیست.
- مدل و permission واقعی سرور مرجع است؛ پنهان‌کردن یک دکمه جای مجوز سرور نیست.
- محاسبات مالی فاکتور با integer و BigInt؛ واحد کاتالوگ فعلی با نرخ مشترک ۶۰۰۰۰۰ به ریال تبدیل می‌شود.
- خروجی مدل زبانی جای محاسبهٔ مالی یا query معتبر نیست؛ دادهٔ سفارش/مشتری دستور قابل اجرای مدل تلقی نمی‌شود.
- عملیات آیندهٔ AI باید پیش‌نمایش، نسخه، تأیید انسانی، idempotency و audit داشته باشند؛ مدل SQL آزاد اجرا نمی‌کند.

## ترتیب توسعه

1. **هستهٔ قابل تست (این نسخه):** ورود، مجوز، داشبورد، عمده، فاکتور، مشاهدهٔ موجودی/سفارش/مشتری/رویداد.
2. **تکمیل عملیات:** ویرایش محصول، نقش‌ها، وضعیت سفارش، اعلان و ثبت زمان رسیدگی؛ تست Android/iOS.
3. **کیفیت و جمع‌آوری داده:** تاریخچهٔ قیمت/هزینه/موجودی، رویدادهای بازدید و کمپین، تعاریف دقیق شاخص‌ها.
4. **تحلیل قابل ارزیابی:** سود، خرید مجدد، کارایی کمپین و گزارش روزانه با منبع و زمان آخرین به‌روزرسانی.
5. **هوش مدیریتی:** دستیار مبتنی بر ابزار، Radar توسعه‌یافته و Brain با شواهد.
6. **قابلیت شاخص:** Future Mirror با فرضیات روشن و مقایسهٔ نتیجهٔ واقعی با پیش‌بینی.

تست و کنترل امنیت در هر مرحله انجام می‌شود، نه فقط در انتهای نقشهٔ راه.

## شرط کنارگذاشتن پنل وب

پوشش همهٔ عملیات ضروری فعلی، ورود آنلاین پایدار، برابری PDF و داده‌ها، تست مجوزها و تعارض،
تست واقعی دستگاه و شبکهٔ ضعیف، داشتن راه بازگشت و تأیید مدیر. تا آن زمان پنل وب حفظ می‌شود.
