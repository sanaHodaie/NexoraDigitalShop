# تطبیق عملیاتی پنل وب و اپ — نسخهٔ ۰.۲

مرجع بررسی: `AdminPanel/src/App.tsx` و تمام componentهای فعال آن؛ APIهای مدیریت موجود حفظ شده‌اند.

| امکانات پنل قبلی | محل در اپ |
|---|---|
| داشبورد، آمار، درخواست‌های تلگرام | خانه و تب درخواست‌ها |
| ایجاد/ویرایش محصول، قیمت ریالی، توضیحات، مشخصات، نشان، بارگذاری تصویر | محصولات ← محصول جدید / ویرایش |
| موجودی و بایگانی | محصولات ← ویرایش / فعال یا غیرفعال |
| فیلتر دسته، جست‌وجوی نام/برند/شناسه و صفحه‌بندی | بالای محصولات؛ نوع کالا نیز افزوده شده |
| افزایش گروهی قیمت بر اساس دسته و برند | محصولات / حساب ← تغییر قیمت گروهی؛ پیش‌نمایش و snapshot |
| قالب XLSX، انتخاب، اعتبارسنجی و ثبت محصولات | محصولات / حساب ← ورود از اکسل |
| فهرست سفارش، جزئیات، فاکتور و گارانتی، لغو و تأیید دستی پرداخت | حساب / خانه ← سفارش‌های سایت ← جزئیات |
| مشتریان، جست‌وجو و لغو نشست‌ها | حساب ← مشتریان فروشگاه |
| گزارش رویداد، فیلتر و فعالیت اخیر | تب رویدادها؛ XLSX/DOCX و بازهٔ تاریخ نیز افزوده شده |
| اعضای خبرنامه، ارتباط با حساب و جست‌وجو | حساب / زنگوله ← خبرنامه؛ شمارندهٔ خوانده‌نشده نیز افزوده شده |
| محتوای بنر اصلی، مجموعه‌ها و محصولات پیشنهادی | حساب ← مدیریت صفحهٔ اصلی |
| مقاله، بخش‌ها، منابع، تصاویر و انتشار | حساب ← مجله و مقاله‌ها |
| نام/توضیحات/ایمیل/تلفن فروشگاه | حساب ← تنظیمات فروشگاه |
| تنظیمات راهنمای خرید و آزمایش پاسخ | حساب ← تنظیم و آزمایش راهنمای خرید |
| روشن/تیره/دستگاه، خروج از حساب و کنترل مجوز | حساب و ورود |

ویرایش محتوا به صورت فرم ساختاریافته با افزودن/حذف موارد، نه انتقال HTML پنل قدیمی است.
عملیات حساس تأیید دارند و همگی با permission سرور اجرا می‌شوند. واردکردن اکسل محصولات جدید را مطابق سیاست قبلی
ابتدا غیرفعال می‌سازد؛ پیش از فعال‌کردن، تصویر معتبر بارگذاری و مشخصات بررسی شود.

مدیریت نقش از رابط، محاسبهٔ سود بدون هزینهٔ معتبر و هوش تصمیم‌گیریِ PDF جزو امکانات آمادهٔ پنل قبلی نبودند
و در این نسخه هم به‌عنوان قابلیت ساخته‌شده معرفی نمی‌شوند. پنل قدیمی برای بازگشت و مقایسه حفظ شده است.
