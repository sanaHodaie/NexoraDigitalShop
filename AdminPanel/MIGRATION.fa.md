# پنل واحد مدیریت نکسورا

تمام امکانات آمادهٔ اپ قبلی در پنل وب `/admin` در دسترس‌اند. اپ Expo و مسیرهای نشست بومی حذف شده‌اند؛
ورود پنل با کوکی HttpOnly و CSRF همان فروشگاه انجام می‌شود. هیچ توکن اپ، رمز پیش‌فرض یا کلید سرویس در مرورگر قرار نمی‌گیرد.
نشانی قبلی `/business` به `/admin` هدایت می‌شود.

| امکان | محل در پنل |
|---|---|
| پوستر، فروش واقعی، آمار و رادار موجودی | داشبورد اصلی |
| آمار و نمودار تلگرام | داشبورد ← درخواست‌های واقعی تلگرام و عمده |
| جزئیات مشتری، نشانی، وضعیت و یادداشت داخلی | درخواست‌های تلگرام و عمده |
| بازبینی فاکتور، ارقام فارسی، جمع دقیق، تأیید، PDF، کد رهگیری و تلاش مجدد ارسال | همان درخواست عمده |
| محصول جدید، ویرایش، توضیحات، مشخصات، تصویر و موجودی | محصولات و موجودی |
| جست‌وجو، فیلتر دسته و نوع کالا، فعال/غیرفعال و بایگانی | محصولات و موجودی |
| افزایش گروهی با پیش‌نمایش و snapshot تأیید | تغییر گروهی قیمت |
| قالب XLSX، پیش‌نمایش خطاها و ثبت محصولات بایگانی | محصولات ← ورود از اکسل |
| فهرست یکپارچهٔ سایت و عمدهٔ تأییدشدهٔ تلگرام، فیلتر منبع و جست‌وجو | سفارشات و فاکتورها |
| نام خریدار، اقلام، آدرس، پرداخت، PDF وزیرمتن، HTML و گارانتی | سفارشات و فاکتورها ← جزئیات و فاکتور |
| لغو سفارش و تأیید پرداخت بررسی‌شده | سفارشات و فاکتورها، مطابق مجوز |
| حساب مشتری، جست‌وجو و لغو نشست‌ها | حساب‌های کاربران |
| نوع رویداد، بازهٔ تاریخ UTC و خروجی XLSX/DOCX | گزارش رویدادهای مدیریت |
| اعضای خبرنامه، آخرین عضویت‌ها و شمارندهٔ خوانده‌نشده برای هر مدیر | زنگوله / اعضای خبرنامه |
| متن‌ها و مجموعه‌های صفحه اصلی | محتوای صفحه اصلی |
| انتشار/ویرایش مقاله، بخش‌ها و منابع | مجله فناوری |
| نام، توضیحات، ایمیل و تلفن فروشگاه | تنظیمات سیستم |
| پیکربندی و آزمایش پاسخ با کاتالوگ | راهنمای هوشمند خرید |
| بررسی اتصال عمومی بک‌اند، بدون نمایش کلید | صفحهٔ ورود ← بررسی اتصال |
| روشن، تیره و هماهنگ با دستگاه | حساب مدیریت؛ دکمهٔ تم نیز بالای صفحه و ورود |

فایل PDF عمده همان سند ذخیره‌شدهٔ ارسالی به مشتری است؛ جمع‌ها با BigInt محاسبه می‌شوند.
هشدار موجودی قاعده‌محور است؛ هیچ نمودار ساختگی به‌عنوان فروش واقعی نمایش داده نمی‌شود.
اعلان خبرنامه در پنل باز هر ۳۰ ثانیه بررسی می‌شود؛ اعلان پس‌زمینهٔ موبایل جزو قابلیت‌های قبلی نبود.
خروجی فایل در مرورگر دانلود می‌شود و می‌توان آن را با امکانات مرورگر/سیستم به اشتراک گذاشت.

## اجرای محلی بدون Docker

ترمینال اول:

```powershell
cd D:\nexoraShop\backend
$env:UV_PROJECT_ENVIRONMENT = ".venv-admin"
uv sync --frozen
uv run --frozen python start.py
```

ترمینال دوم:

```powershell
cd D:\nexoraShop
npm ci --no-audit --no-fund
npm run dev
```

نشانی: `http://localhost:3000/admin`. Vite درخواست‌های `/api` را به بک‌اند محلی پورت ۸۰۰۰ می‌فرستد؛
دیگر Expo، پورت ۸۰۸۱ یا EXPO_PUBLIC_API_URL لازم نیست. برای ایجاد/بازتنظیم مدیر محلی روی PostgreSQL لوکال:

```powershell
cd D:\nexoraShop\backend
$env:UV_PROJECT_ENVIRONMENT = ".venv-admin"
uv run --frozen python -m app.setup_local_admin adminpannel@nexora.com
```

رمز دو بار مخفی دریافت می‌شود. حساب محلی با حساب آنلاین متفاوت است.
نسخهٔ آنلاین پس از دیپلوی Vercel در `https://nexora-digital-shop.vercel.app/admin` است؛
از ایمیل/رمز حساب مدیر همان دیتابیس آنلاین استفاده کنید. بک‌اند Render هم باید نسخهٔ جدید باشد و migration 0012 موجود باشد.

## بررسی دستی

۱. قبل و بعد از ورود، تغییر تم و دکمهٔ چشم رمز را امتحان کنید.
۲. در محصولات، دسته و نوع کالا را انتخاب، توضیحات را ویرایش و فعال/غیرفعال‌کردن را بررسی کنید.
۳. برای اکسل و افزایش گروهی، اول پیش‌نمایش و سپس تأیید را امتحان کنید.
۴. یک درخواست آزمایشی از بات بسازید، فاکتور عمده را بازبینی/تأیید و PDF را دانلود کنید؛ ارسال واقعی تلگرام به تنظیمات بات و worker بستگی دارد.
۵. در رویدادها، بازهٔ تاریخ بدهید و اکسل/ورد را دانلود کنید.
۶. در خبرنامه عضو آزمایشی بسازید؛ شمارندهٔ زنگوله باید زیاد شود و با بازکردن بخش خبرنامه خوانده شود.
۷. جزئیات یک سفارش و PDF، نشانی و مرجع پرداخت را بررسی کنید.

بررسی خودکار این تغییر: TypeScript، بیلد Vite، آزمون‌های backend و مرورگر با پاسخ‌های ساختگیِ API؛
تست مرورگر دادهٔ واقعی تغییر نمی‌دهد و پیام تلگرام ارسال نمی‌کند. تست حساب آنلاین و ارسال واقعی را روی محیط خودتان انجام دهید.

درخواست عمدهٔ تأییدشدهٔ تلگرام به‌صورت خودکار در «سفارشات و فاکتورها» با برچسب تلگرام دیده می‌شود؛ سفارش پرداخت‌شده یا رزرو موجودی سایت برای آن ساخته نمی‌شود.
فاکتورهای جدید قالب آبی، محل مهر و امضای مدیریت در پایین چپ و راهنمای ارسال و گارانتی دارند.
PDFهای صادرشدهٔ قبلی برای حفظ یکسان بودن سند مدیر و مشتری بازتولید نمی‌شوند؛ برای دیدن قالب جدید، درخواست آزمایشی جدید تأیید کنید.

فهرست درخواست‌های تلگرام به ردیف‌های خلاصه تبدیل شده است. با «جزئیات سفارش»، درخواست اولیه، اقلام، نشانی، یادداشت داخلی و مراحل تأیید/فاکتور باز می‌شود. جست‌وجو و انتخاب ۲۰/۵۰/۱۰۰ ردیف در صفحه در دسترس است.
فاکتور عمده از همان قالب نمایشی و چاپی سفارش سایت استفاده می‌کند؛ HTML و چاپ به دادهٔ ذخیره‌شدهٔ فاکتور متکی‌اند و PDF اصلی مشتری همچنان همان فایل محفوظ است.
نوار اسکرول منو پنهان است؛ پیمایش با ماوس، لمس و کیبورد برقرار می‌ماند.
