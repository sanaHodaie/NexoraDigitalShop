# محصولات منتخب دسته‌بندی‌ها

سه مسیر React Router برای مجموعه‌های اولیه وجود دارد:

- `/category/smartphones`: ده گوشی هوشمند
- `/category/laptops`: ده لپ‌تاپ، مینی پی‌سی و آل‌این‌وان
- `/category/audio`: ده هدفون، هندزفری و اسپیکر

محصولات این مجموعه‌ها در `backend/data/catalog-products.json` هستند. قیمت‌ها
و پیکربندی‌ها نمونهٔ آزمایشی هستند، نه پیشنهاد فروش یا قیمت روز. تصاویر SVG
نمایشی و محلی‌اند؛ برای فروش واقعی، تصاویر و مشخصات دقیق کالای قابل عرضه را
جایگزین کنید. امتیاز یا نظر ساختگی به محصولات جدید اضافه نشده است.

`python start.py` یا `python -m app.seed` محصولات جدید را به دیتابیس اضافه
می‌کند. اجرای مجدد seed قیمت، موجودی، اطلاعات محصولات قبلی یا سبد کاربران را
بازنویسی نمی‌کند. تغییر فایل JSON پس از اولین seed، اطلاعات رکورد موجود را
تغییر نمی‌دهد؛ ویرایش اطلاعات فروشگاه باید جداگانه و با دسترسی مجاز انجام شود.

انتخاب ده محصول هر صفحه در `src/data/catalog.js` تعریف شده است. محصولات قدیمی
صفحهٔ اصلی حفظ شده‌اند. کارت‌ها قیمت و موجودبودن را از API می‌گیرند و عملیات
سبد خرید و علاقه‌مندی‌ها از همان APIهای فعلی استفاده می‌کند.

تصاویر و داده‌های اولیه با `node scripts/build-demo-catalog.mjs` تولید شده‌اند؛
این دستور تغییرات دستی فایل داده‌های نمونه و تصاویرش را بازنویسی می‌کند.

تست‌ها:

```powershell
node --test scripts/catalog.test.mjs
cd backend
& .\.venv-audit\Scripts\python.exe -m pytest tests/integration/test_catalog.py -q
```

برای بررسی مرورگر، بک‌اند محلی و فرانت‌اند روی پورت 3002 را روشن کنید و سپس
`node scripts/check-catalog.mjs` را از ریشه اجرا کنید. این بررسی داده‌های حساب
را تغییر نمی‌دهد. مسیر مرورگر و آدرس فرانت‌اند با `NEXORA_CHROME` و
`NEXORA_UI_URL` قابل تنظیم‌اند.
